What do I need to run Engram?

The deployment guide recommends 4 CPU cores and 8 GB RAM, with 16 GB or more preferred. Allow storage for PostgreSQL, documents, Ollama models and encrypted backups. Configure secrets and an administrator before use.

Is Engram open source?

Engram is source-available and free for personal, noncommercial self-hosting. Workplace use, commercial integrations and managed hosting require separate written permission. Read the license and usage guide.

Where does AI processing happen?

Engram uses Ollama for local embeddings and extraction on your infrastructure. Optional connectors communicate with their external services. You control which sources and clients you connect.

Can I use the mobile app or buy managed hosting?

The stable server release is v2.7.0. Native iOS and Android companions remain preview work with device qualification still open; Gmail is also a preview connector. This page offers self-hosting, not a managed subscription. For commercial enquiries, contact Jayden.
